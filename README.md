# class-y

Mobile App (iOS/Android) für Gyms/Studios und ihre freiberuflichen/angestellten Trainer:innen,
um gegebene Kurse zu tracken, Studios Monitoring-Übersichten zu geben und (später) Gutschriften/Belege
automatisiert abzuwickeln.

Nicht zu verwechseln mit dem separaten Projekt `classy` (ohne Bindestrich) unter
`../classy`.

Details zu Stack, Datenmodell und Roadmap: siehe [`PLANNING.md`](./PLANNING.md).
Konventionen für die Entwicklung (sobald Code existiert): siehe [`CLAUDE.md`](./CLAUDE.md).
